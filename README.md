Introduction 
Hearthwell is an online retailer who sells home and kitche products. Free-text data comes in as product review from website daily and support tickets from the support tools weekly. The pipeline cleans the data, assigns topic and sentiment, stores it in a database (Snowflake), and shows it on the dashboard which refreshes weekly. It matters to customers and the company because the communication between customer support and product manager is late because support team has to review all of the customer feedback manually which consumes a lot of time. This leads to problem of having no answer or answering questions about product complaints late.
